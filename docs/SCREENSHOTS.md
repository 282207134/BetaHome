# 全界面截图索引

本次截图来自 Android 15 / API 35 模拟器，画布为 428 × 926。浅色与深色各 58 张，共 116 张，包含 54 个命名路由、启动页与三个弹层状态。图片由运行中的 Flutter 页面生成，使用演示资料、收藏与订单展示完整内容。

主要界面预览见项目根目录的 [README](../README.md)。设计画板对应关系见 [DESIGN_MAPPING.md](DESIGN_MAPPING.md)。
