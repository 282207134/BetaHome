# Pixso 设计与应用页面对应表

来源：Pixso「Beta Home」→ Design（页面 ID `97:1810`），设计基准 428 × 926。

原稿共 76 个浅色画板与 76 个深色画板，其余为分区标题。空白、输入中、填写完成复用同一 Flutter 页面；适配时保留滚动内容，不将整张设计截图铺作交互界面。所有可操作页面由 Flutter 控件实现。地图底图为原稿导出的插画，照片和头像来自原稿。

应用截图按 `screenshots/light/` 和 `screenshots/dark/` 保存。这里的截图是运行中的 Android 应用，原稿导出图单独位于 `design/`。同一页面的多个输入/滚动状态在下表指向同一个页面截图，键盘由系统实际输入时显示。

## 实现时的调整

- 补全原稿部分按钮中缺失的文字，提供明确的操作入口。
- 原稿长页面改为可滚动列表，底部主要操作固定在安全区域内。
- 日期使用当前月份与后续日期，避免固定在原稿的 2023 年。
- 租赁与购买共享支付、PIN、完成和凭证组件，金额根据当前流程计算。
- 原稿通知筛选以“只看未读”交互实现；收藏保留排序弹层。
- 使用 Flutter Material 线性图标替代部分原稿自定义图标，保留蓝色、尺寸和层级。
- 地图、社交登录、支付与通话明确显示演示状态；语言页保存偏好，界面文案仍使用设计稿英文。
